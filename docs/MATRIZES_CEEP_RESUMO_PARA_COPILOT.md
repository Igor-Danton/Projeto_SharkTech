## Observações importantes para o desenvolvimento

1. Não repetir no banco/site toda a FGB para cada curso se a aplicação puder reutilizar uma estrutura comum.
2. O diferencial de cada curso deve ser cadastrado principalmente em:
   - nome do curso;
   - carga horária total;
   - turno;
   - componentes técnicos;
   - carga horária do itinerário por série;
   - carga horária total por série.
3. A tabela T/P dos PDFs representa a distribuição teórica/prática por série. Para uma versão enxuta do site, a lista de componentes e as cargas consolidadas são suficientes; só manter T/P se o sistema realmente precisar exibir isso.
4. Não transformar códigos ausentes em códigos inventados.
5. Não usar conteúdo de outras fontes para completar informações que não aparecem nas matrizes.

## Inconsistências/alertas encontrados nos próprios PDFs

- Técnico em Química: a tabela mostra 33 aulas semanais na 3ª série em uma parte, enquanto a tabela da página padrão apresenta 32; tratar como divergência documental e não escolher automaticamente um valor.
- Técnico em Meio Ambiente: a tabela mostra 34 aulas semanais na 3ª série, mas a nota de rodapé menciona 32; preservar a divergência para validação.
- Técnico em Edificações: ocorre a mesma divergência entre a tabela (34 na 3ª série) e a nota de rodapé (32).
- Algumas matrizes exibem P/NP em componentes da Formação Geral Básica. Esses marcadores não devem ser convertidos arbitrariamente para números.
- Os PDFs são matrizes curriculares oficiais apresentadas com estruturas repetidas; esta consolidação deliberadamente não reproduz todo o conteúdo repetitivo de cada página.
