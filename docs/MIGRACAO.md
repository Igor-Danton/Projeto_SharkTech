# Migração do site atual

O novo portal substitui o site institucional atual (https://ceepcuritiba.com.br/novo/).
Isso exige uma etapa própria: inventariar o conteúdo existente e decidir o destino de
cada item, em vez de copiar tudo.

## Como funciona

Cada conteúdo do site atual recebe uma classificação:

| Classificação | Significado |
|---|---|
| **Manter** | vai para o novo site sem mudança |
| **Atualizar** | conteúdo certo, dado desatualizado |
| **Reescrever** | assunto necessário, texto ruim ou confuso |
| **Reorganizar** | conteúdo bom, no lugar errado da navegação |
| **Remover** | duplicado, obsoleto ou fora do escopo |
| **Pendente** | precisa de decisão ou informação da escola |

## O que observar em cada página

- a informação ainda é verdadeira?
- ela está no lugar onde o usuário procuraria?
- quantos cliques são necessários para chegar até ela a partir da home?
- ela repete outra página?
- funciona no celular?
- o link ainda abre? (links quebrados são candidatos a remoção)

## Redirecionamentos

Se o endereço de uma página mudar, o endereço antigo não pode virar erro 404 —
quem tem o link salvo, ou quem chega pelo Google, precisa cair na página nova.
Monte a lista **de → para** durante o inventário e implemente os redirecionamentos
no servidor no momento da publicação.

## Fora do escopo

Não migrar nem recriar: sistema oficial de matrícula, sistemas da SEED-PR, redes
sociais da instituição. Onde esses serviços aparecerem, o novo site apenas encaminha
o usuário para o canal oficial.
